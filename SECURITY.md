# Security policy

OpenShift Community Tools is a community project, not officially supported by Red Hat.

## Reporting a vulnerability

Please **don't open a public issue** for a security problem. Report it privately through **GitHub security advisories** on the affected repository (Security tab → "Report a vulnerability"). Include what is affected, how to reproduce it, and the impact you see.

Maintainers aim to acknowledge reports within a few working days and to coordinate a fix and release before details are made public.

## Scope

The storefront, `backend-security-kit`, the catalog, and the extensions in the openshift-community-tools GitHub organization. How OCT handles permissions, backends and installs is described in [docs/security-model.md](docs/security-model.md).
